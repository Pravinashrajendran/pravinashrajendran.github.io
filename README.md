# Pravinash — CyberLab Website

This repository powers the GitHub Pages website for the interactive cybersecurity project explorer.

## Website
Once GitHub Pages is enabled and deployment completes, visit:

**https://pravinashrajendran.github.io/**

## Local preview
Open `index.html` in a browser, or open this repository in VS Code and use Live Server.

## What's included
- Interactive honeypot-to-firewall workflow with a safe simulated SSH-event counter.
- Splunk SOC detection workflow with illustrative dashboard values and searchable sample events.
- Clickable stages, plain-English explanations, and a security glossary.

## Important
This is a front-end educational simulation. It does not connect to live Cowrie, Splunk, iptables, Elasticsearch, Logstash, or Kibana systems. Sample metrics are illustrative and no traffic is sent or firewall rule is applied.
